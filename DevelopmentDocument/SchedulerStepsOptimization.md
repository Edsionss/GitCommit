# Scheduler 任务参数步骤条优化开发设计文档

## 功能概述
优化 Scheduler.vue 页面的样式，将任务参数配置改为步骤条形式，提升用户体验和界面的可操作性。主要改进点：
1. 将任务创建/编辑流程改为步骤条形式
2. 第一步：基本任务信息（名称、Cron表达式、动作类型）
3. 第二步：任务参数配置（根据动作类型显示不同的参数配置）
4. 优化整体UI样式，使用全局CSS变量保持主题一致性

## 技术方案
1. 使用 Ant Design Vue 的 Steps 组件实现步骤条
2. 将原有的 TaskForm 组件改造为步骤条形式
3. 使用全局CSS变量优化样式，确保主题一致性
4. 优化表单验证和用户体验

## 依赖项
无需安装新的NPM包，使用现有的 Ant Design Vue 组件库

## 数据库设计
无需修改数据库结构，仅优化前端展示方式

## API设计
无需修改现有API，复用现有的schedulerApi接口

## 模块划分
1. **Scheduler.vue**: 主页面，优化样式和布局
2. **TaskForm.vue**: 改造为步骤条形式
3. **TaskStepsForm.vue**: 新建步骤条表单组件（可选，也可直接改造TaskForm）
