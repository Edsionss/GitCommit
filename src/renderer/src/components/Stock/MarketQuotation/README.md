# 市场行情 (MarketQuotation) 组件开发计划

## 1. 总体目标

开发一个全面的市场行情展示组件，为用户提供多维度、实时性的股市信息。该组件将作为信息聚合的仪表盘，整合包括行业板块、龙虎榜、资金流向、全球股市和热门股票榜等多个核心功能模块。

## 2. 组件架构

`MarketQuotation` 组件将作为父容器，采用模块化设计，内部包含以下五个子组件。每个子组件负责一个特定的功能领域，并通过异步加载和合理的布局展示。

- **主组件**: `MarketQuotation/index.vue`
- **子组件**:
  - `IndustrySector.vue`: 行业板块表现
  - `DragonTigerList.vue`: 龙虎榜数据
  - `CapitalFlow.vue`: 市场及个股资金流向
  - `GlobalMarkets.vue`: 全球主要股指行情
  - `HotStocks.vue`: 热门股票排行榜
